# netflip-x

> 内网 / 互联网一键切换工具：点一下，就能在内网固定 IP 和外网 DHCP 自动获取之间来回切换，不用再手动改 IP。

单文件 · 免安装 · 双击即用

## 怎么用

1. 下载 `上网环境设置工具.exe`
2. 右键 → **以管理员身份运行**（弹窗点「是」）
3. 用内网时，点「**内网固定IP模式**」卡片
4. 用外网时，点「**外网DHCP自动获取**」卡片
5. 想改 IP / 网关 / DNS，点右上角「**参数设置**」，保存即生效

> 打开后会自动识别当前是内网还是外网模式，对应卡片会亮起绿色「已应用」。
